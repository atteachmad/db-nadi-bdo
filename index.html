About DB-NADI

DB-NADI (Dashboard NADI) adalah sistem monitoring terpadu antrian dan operasional bongkar muat secara Real-Time.


Versi Sistem:
- v1.0: Inisialisasi awal UI Mobile.
- v1.1: Integrasi Backend Google Sheets & Auto Timer.
- v1.2: Integrasi Validasi Foto.
- v1.3: Fitur Audio-to-Text, Geolocation, Export Data, & Modul Pencarian Global.
- v2.1.0: Locked TV Mode on Refresh, Clean Mobile UI, Burger Integration.
- v3.0 (Terbaru): Dukungan Multi-Lokasi, Integrasi AI Lanjutan, Alarm Progresif, Backend Authentication.


✖
Help Center

Cara Menggunakan DB-NADI:

  • Security: Input kedatangan armada beserta kota asal (Origin).
  • Checker: Monitoring tugas bongkar muat di handphone lapangan.
  • TV Dashboard: Otomatis terkunci sebagai tampilan utama saat halaman di-refresh.

Tentang Proyek

db-NADI dikembangkan sebagai solusi cerdas berbasis data untuk mengoptimalkan proses monitoring armada di lapangan secara komprehensif. Dengan mengintegrasikan sistem real-time, validasi geolokasi, dan analitik AI, aplikasi ini bertujuan untuk menekan waktu tunggu SLA, mendeteksi hambatan operasional, serta meningkatkan efisiensi dan produktivitas tim operasional dari pintu kedatangan (gate) hingga proses bongkar muat (dock).
